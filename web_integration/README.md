# Global Olympic Sports Performance Analytics (1992-2026)

## How to Run Locally:
1. Extract this ZIP archive into a folder.
2. Open a terminal inside the extracted folder.
3. Install Flask:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the server:
   ```bash
   python app.py
   ```
5. The application will automatically open in your browser at `http://127.0.0.1:8000`.
